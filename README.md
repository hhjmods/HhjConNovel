# 활협전 콘문학 에디터

디시콘을 불러와 원하는 방식으로 분류하고 콘문학 원고를 작성할 수 있는 웹 편집기입니다.

## 실행

https://hhjmods.github.io/HhjConNovel/

## 주요 기능

- 보유 디시콘 목록 동기화
- 사용자 콘묶음 생성 및 관리
- 여러 디시콘 동시 선택
- 드래그 앤 드롭으로 콘 분류
- 콘묶음 내 순서 변경
- 같은 콘을 여러 콘묶음에 분류
- 콘묶음 내보내기 및 불러오기
- 콘과 대사를 이용한 원고 작성
- 작성 중인 데이터 자동 저장

## 처음 사용하는 경우

1. Tampermonkey를 설치합니다.
2. **활협전 콘문학 에디터**를 실행합니다.
3. **DC 브리지 설치**를 눌러 DC 브리지를 설치합니다.
4. 같은 브라우저에서 DCInside에 로그인합니다.
5. 사용할 갤러리의 글쓰기 페이지 주소를 입력합니다.
6. **DC 동기화**를 누릅니다.

동기화가 완료되면 불러온 디시콘을 자유롭게 분류하고 원고에 사용할 수 있습니다.

## 개인정보 및 데이터 처리 안내

활협전 콘문학 에디터는 사용자의 DCInside 아이디나 비밀번호를 입력받거나 저장하지 않습니다.

디시콘 동기화는 사용자가 현재 브라우저에서 로그인해 둔 DCInside 세션을 이용하며, 로그인 정보나 비밀번호를 별도의 서버같은 다른 장소로 전송하지 않습니다.

동기화한 디시콘 목록, 직접 만든 콘묶음, 작성 중인 원고 등의 사용자 데이터는 별도의 서버나 개발자에게 전송·저장되지 않고 **사용자 본인의 브라우저 안에 저장됩니다.**

따라서 다른 사용자나 개발자가 해당 데이터를 열람하는 구조가 아니며, 다른 PC나 다른 브라우저로도 자동 전송되지 않습니다.

단, 브라우저의 사이트 데이터를 삭제하면 저장된 데이터도 함께 삭제될 수 있으므로 필요한 콘묶음은 내보내기 기능을 이용해 백업하는 것을 권장합니다.

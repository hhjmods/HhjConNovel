활협전 콘문학 에디터

사용법 Tampermonkey 설치 DC 브리지 설치 활협전 콘문학 에디터에서 디시콘을 불러오고 글을 DCInside에 올리려면 아래 두 가지를 설치해야 합니다. Tampermonkey DCInside 페이지에서 DC 브리지를 실행하는 브라우저 확장 프로그램입니다. DC 브리지 현재 브라우저에 로그인된 DCInside 계정의 보유 디시콘을 동기화하고, 작성내용 복사로 작성한 콘문학을 dc에 붙혀넣는 과정을 보조합니다. 설치 순서 ① Tampermonkey 설치 ② DC 브리지 설치 (Tampermonkey스크립트) ③ DCInside 로그인 ④ 편집기에서 DC 동기화 Chrome 추가 설정 Chrome에서는 사용자 스크립트 실행 권한을 따로 켜야 할 수 있습니다. ① 주소창에 chrome://extensions를 입력해 열거나, 오른쪽 위 점 세 개(⋮) 버튼을 눌러 확장 프로그램 → 확장 프로그램 관리로 들어갑니다. ② 목록에서 Tampermonkey를 찾아 세부정보를 누릅니다. ③ 사용자 스크립트 허용을 켭니다. 동기화가 안 될 때 편집기는 DCInside 아이디나 비밀번호를 입력받지 않습니다. 동기화가 작동하지 않으면 DCInside 로그인 상태와 Tampermonkey에서 브리지가 켜져 있는지 확인하고 DC 브리지를 다시 설치한 후 Ctrl+F5를 눌러 강력 새로고침을 해보세요. 만약 그래도 안된다면 우측 상단의 에디터 백업을 클릭해 에디터를 백업하여 저장한 후 아래의 활협전 콘문학 에디터의 데이터의 사이트 데이터를 지우고 새로 로드하는 과정을 순서대로 진행하세요. (백업을 진행하는 이유는 사이트 데이터를 지우면 원고, 콘 등 모든 데이터가 삭제되기 때문입니다.) ① Chrome 주소창에 chrome://settings/content/all을 입력해 엽니다. ② 페이지 우측 상단의 사이트 필터링 칸에 hhjmods.github.io를 입력합니다. ③ hhjmods.github.io 항목의 휴지통 아이콘을 눌러 삭제를 확인합니다. 모든 사이트 데이터 삭제는 모든 사이트의 데이터를 지우는 버튼이니 절대 누르지 마세요. ④ 편집기 페이지로 돌아와 Ctrl+F5를 눌러 강력 새로고침합니다.
